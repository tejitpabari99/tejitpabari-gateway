## Overview
A marketplace for selling unused API tokens at discounted rates.

## Features
- Platform for users to sell their unused API tokens
- Buyers can purchase tokens at cheaper rates
- Provides API key to buyers for seamless integration
- Internally routes requests to the seller's API key
- Acts as intermediary between buyers and sellers

## Notes
Similar concept to rouguetokens.ai. Many people have unused tokens that could be monetized through this type of marketplace.
