# cc-gateway → Firebase (static) — Brainstorm Brief

## TL;DR

cc-gateway moves off its VPS onto Firebase project `tejitpabari-99` as two static Hosting sites (`cc.` app, `go.` redirector) with no server code at all — free Spark plan, no Cloud Functions. Data moves from local files to Firestore, auth moves from shared password to Google sign-in with an admin email allowlist enforced by Firestore rules, AI auto-rank moves from Anthropic (server key) to Gemini via Firebase AI Logic (no key in client), and short-link click counting moves to GA4 events. LinkedIn is removed.

## Problem

cc-gateway (ideas/notes + links + go. short links, with guest read-only mode) runs as a Node server under pm2 on a VPS that isn't the "official" home and whose setup is unverified. The owner wants it hosted alongside the personal website on Firebase, with as little infrastructure to maintain as possible. Sole user: the owner (admin); public visitors are read-only guests.

## Design

### Parts

| Part | What it does | Depends on |
|---|---|---|
| `cc` SPA | SvelteKit `adapter-static` with SPA fallback (`index.html`); routes `/`, `/ideas`, `/ideas/[slug]`, `/ideas/rank`, `/links`, `/settings`; login = "Sign in with Google" button | Firebase JS SDK (app, auth, firestore, ai, app-check) |
| `src/lib/firebase.js` | Single init of app/auth/db/AI/App Check; exports `role` store: `admin` if signed-in email ∈ allowlist else `guest` | Public Firebase web config (not secret) |
| Data layer (`src/lib/ideas.js`, `links.js`, `settings.js`) | Same function surface as today, reimplemented over Firestore | `firebase.js` |
| Firestore | `ideas/{slug}` (frontmatter fields + `body` markdown), `links/{slug}`, `settings/main` | — |
| `firestore.rules` | Write: `request.auth.token.email == '<owner>' && email_verified`. Read ideas/links collections: admin, or `settings/main.guestVisibility['/ideas'|'/links'] == true`. `links/{slug}` `get` public (go. needs it), `list` admin or guest-visible. `settings/main` readable by all | — |
| AI rank | Client builds same prompt as current Anthropic route, calls Gemini Flash via Firebase AI Logic, writes scores + analysis to idea doc (admin only) | App Check (reCAPTCHA Enterprise) |
| `go` site | Static `index.html` + small inline script; Firestore REST `GET` of `links/{slug}` (no SDK, fast); 404 / 410-expired pages; `gtag('event','go_click',{slug})` with ~300ms `event_callback` timeout, then `location.replace(url)` | Firestore public `get`, GA4 |
| Migration script | One-time Node script with admin service account: parse `content/ideas/*.md` (gray-matter), `links.json`, `settings.json` → Firestore; drop `clicks`, `lastClicked`, `redirectType` | Service account key (local only, not committed) |
| `firebase.json` / `.firebaserc` | Hosting targets `cc` → `build/`, `go` → `go/`; rules deploy; project `tejitpabari-99` | — |

### Guest UI

Unchanged rule from CLAUDE.md, now client-side: hide write actions when `role === 'guest'`; page guard redirects guest to sign-in if page not toggled visible. Rules are the real enforcement — UI hiding is convenience only. `CLAUDE.md` needs updating (API routes / dashboard proxy / LinkedIn sections become obsolete).

### Failure modes

| Failure | Behavior | Who notices |
|---|---|---|
| Gemini quota/App Check failure | Rank button shows error; idea stays unranked | Owner, in UI |
| Firestore read denied (guest, page hidden) | Redirect to sign-in | Visitor |
| go. slug missing/expired | Static 404/410 page | Visitor |
| GA blocked | Redirect still happens (timeout), click uncounted | Nobody — accepted |
| Non-owner signs in with Google | Treated as guest; rules deny writes | — |

### Verification

Rules unit tests with Firebase emulator (admin write ok, guest write denied, hidden-page read denied, public link `get` ok/`list` denied); local emulator run of SPA; go. page tested with live, missing, expired slugs; post-cutover smoke test on both domains.

## Owner-only tasks (after build)

1. Firebase console: add Hosting sites `cc` and `go`; connect custom domains `cc.tejitpabari.com`, `go.tejitpabari.com`.
2. Cloudflare: repoint `cc` and `go` records to values Firebase gives, DNS-only (grey cloud).
3. Firebase console: enable Firestore, Google sign-in provider (add both domains to authorized domains), Firebase AI Logic (Gemini Developer API), App Check with reCAPTCHA.
4. Create service account key for migration script (or run it yourself).
5. Decommission old VPS after cutover verified.

## Non-goals

SSR; Cloud Functions/Blaze; real HTTP 301/302 for go.; in-app click counts; local ideas mirror; LinkedIn tool; multi-admin; Claude/OpenAI models.

## Open risks

| Risk | Cheapest test |
|---|---|
| Firebase AI Logic free tier / Spark availability or App Check setup differs from assumption | Owner accepts small cost: if Spark doesn't cover it, switch to Blaze (pay-as-you-go) with a budget alert; still no Cloud Functions. Verify with a 10-line test call before porting rank |
| Gemini rank quality differs from Claude | Re-rank 3 known ideas, compare scores |
| Firestore rules can't cleanly express "guest read allowed if settings toggle" (needs `get()` on settings per read) | Write rule + emulator test first; fallback: mirror toggles into a public `visibility` doc |
| JS redirect latency/flash on go. noticeable (link-preview unfurl showing go. page explicitly accepted by owner) | Measure on phone after deploy; upgrade path: Cloudflare Worker |
| Old VPS still answering during DNS switch | Lower TTL beforehand; verify via `curl -sI` after switch |
